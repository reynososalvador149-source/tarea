🧩 Objetivo del documento

Registrar los cambios más importantes del proyecto y relacionar cada commit con una actividad de la metodología Scrum, demostrando cómo Git funciona como herramienta de seguimiento y control del progreso.

📝 1. Relación entre Git y Scrum

En Scrum, el desarrollo se divide en entregas incrementales llamadas sprints.
Cada commit realizado en Git representa:

Un avance pequeño y verificable

Un incremento del producto

Un registro histórico del trabajo

Evidencia del cumplimiento de una actividad del sprint

Git permite visualizar qué se hizo, cuándo y por qué, lo que facilita la transparencia del proyecto.

📈 3. Cómo Git ayuda a monitorear el proyecto

Git no solo controla versiones; también:

✅ Ayuda a visualizar el progreso

Con git log o en GitHub puedes ver cómo el proyecto avanza commit por commit.

✅ Muestra claramente quién hizo cada cambio y por qué

Los mensajes de commit funcionan como mini-reportes.

✅ Permite rastrear decisiones importantes

Por ejemplo, cuando resolviste un conflicto, quedó documentado como parte del proceso.

✅ Estructura el trabajo según las fases de Scrum

Cada rama representa un área:

main → versión estable

desarrollo → sprint development

pruebas → testing

documentacion → documentación del sprint

modelo_hibrido → planificación extendida

🧾 4. Conclusión

El uso de Git permitió:

Controlar el avance del proyecto paso a paso

Organizar el trabajo de acuerdo con Scrum

Documentar decisiones y problemas (como resolver conflictos)

Mantener versiones separadas para desarrollo, pruebas y documentación

Crear registros que sirven como evidencia para la clase

Git no solo guarda código, sino que funciona como un historial detallado del proyecto y como herramienta profesional para la gestión del desarrollo.
